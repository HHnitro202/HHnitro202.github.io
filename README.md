# Portfólio de Felipe Gai

Site estático em HTML e CSS. O portfólio, os estilos e o currículo em PDF funcionam sem servidor de aplicação ou etapa de compilação.

## Publicar no GitHub Pages

1. Extraia o ZIP e envie seu conteúdo para a raiz de um repositório, na branch `main`. Inclua o arquivo oculto `.nojekyll`.
2. Abra **Settings → Pages** e, em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione **main** e **/ (root)** e salve. O endereço publicado aparece nas configurações de Pages quando o deploy terminar.

Use o repositório `<usuário>.github.io` para publicar na raiz do domínio do GitHub Pages. Em outro repositório, o site fica no caminho `/<repositório>/`. Os links para arquivos locais são relativos e funcionam nos dois formatos.

[Documentação do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Editar

- `index.html` contém o texto, os projetos, a trajetória e os links.
- `assets/site.css` contém as cores, os estilos e os ajustes para telas de diferentes larguras.
- `assets/Felipe_Gai_Curriculo.pdf` é o arquivo oferecido para download.

Abra `index.html` no navegador para conferir alterações locais.
